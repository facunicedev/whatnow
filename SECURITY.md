# Security Policy

whatnow runs inside Claude Code and only reads/writes `PROGRESS.md` and a handoff file in the folder where you open a session. It makes no network calls.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately with
[GitHub's private vulnerability reporting](https://github.com/facunicedev/whatnow/security/advisories/new).

Expect an acknowledgement within a week.

## Supported versions

Only the latest release.
